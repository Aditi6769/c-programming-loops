# C Programming: Loops & Control Flow

This repository contains basic C programs designed to practice loop structures (`for`, `while`, `do-while`) and numerical computations.

## 📌 Included Programs

* `printing_first_10_natural_numbers.c` – Prints the numbers from 1 to 10.
* `printing_first_10_even_numbers.c` – Outputs the first 10 even integers.
* `printing_first_10_odd_numbers.c` – Outputs the first 10 odd integers.
* `printing_n_natural_numbers.c` – Accepts user input `N` and prints numbers up to `N`.
* `printing_first_n_even_numbers.c` – Prints the first `N` even numbers.
* `printing_first_n_odd_numbers.c` – Prints the first `N` odd numbers.
* `sum_of_n_numbers.c` – Calculates and displays the total sum of `N` numbers.
